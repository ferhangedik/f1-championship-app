# F1 Championship Data Analysis

Engineering diploma project — Akademia Finansów i Biznesu Vistula.

A web application that loads real Formula 1 data into a PostgreSQL database and
presents standings, race details, driver comparisons and analytics with Flask.

## Status
In development.

## Tech stack
- Python 3, Flask
- PostgreSQL 18 (raw SQL with psycopg 3, no ORM)
- Bootstrap 5, Chart.js
- Data: Jolpica-F1 (Ergast) API, FastF1
